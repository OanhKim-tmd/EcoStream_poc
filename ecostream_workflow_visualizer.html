📡 Cách Mở & Dùng Live Workflow Monitor Trong App
1. Khởi động máy chủ Web Local:
python -m ecostream.app

Server sẽ chạy tại địa chỉ http://127.0.0.1:8000/.

2. Truy cập Live Monitor:

Mở trình duyệt gõ: http://127.0.0.1:8000/monitor hoặc click nút "📡 Live Monitor" ở góc phải trên cùng thanh header của trang chủ.

3. Các tính năng chính trên trang Live Monitor:
  • Run Selector: Dropdown danh sách các phiên chạy trong thư mục runs/.
  • 5-Phase Lifecycle Stepper: Đèn tín hiệu tiến độ % từ Ingestion → Discovery → Subagents → Math → Synthesis.
  • Intermediate JSON Inspector: Xem trực tiếp dữ liệu trung gian scope1_extracted.json, query_log.json, assumption_log.json...
  • Polling nhịp 3 giây: Tự động thăm dò trạng thái thời gian thực mà không cần tải lại trang.
